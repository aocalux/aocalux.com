What is Firefox as PDF Viewer?

Firefox as PDF Viewer is a custom userChrome.css stylesheet that gives Firefox a cleaner, more focused layout for viewing PDF documents. It hides selected browser interface elements, including the address bar, to reduce distractions and leave more room for the document. The stylesheet changes Firefox's appearance only; Remove or disable the stylesheet to restore Firefox's usual interface.

What does the stylesheet affect?

userChrome.css customizes Firefox's browser interface for the profile where it is installed. The stylesheet does not alter website content, PDF files, or Firefox's PDF rendering. Since Firefox can change its interface between releases, a browser update may affect how the customization looks or works. If the modifications stop working, check for updates to the stylesheet on this site or if it has'nt been updated yet let me know (I've tested it on version 157.0.1 on Ubuntu).

How do I install it?

To install Firefox as PDF Viewer, follow these steps:
  1. Download the userChrome.css file from the GitHub repository.
  2. Open Firefox and go to Settings, set the home page to about:pdf to open the Firefox PDF viewer / editor page on startup.
  3. Navigate to about:support using the address bar to find your profile folder.
  4. Open the profile folder and create a chrome folder if it does not already exist.
  5. Place the downloaded userChrome.css file inside that chrome folder.
  6. In Firefox, open about:config, search for toolkit.legacyUserProfileCustomizations.stylesheets, and set it to true.
  7. Restart Firefox to apply the new PDF viewer layout.

How do I restore Firefox's usual interface?

Remove or rename userChrome.css in the profile's chrome folder, then restart Firefox. You can also set toolkit.legacyUserProfileCustomizations.stylesheets to false in about:config to disable custom user stylesheets. The address bar is hidden, not removed: focus it by pressing Ctrl+L (or Cmd+L on macOS), then enter a Firefox address such as about:settings or about:config, you will also see autocomplete suggestions just like if the address bar were visible.

What should I check if the style does not appear?

Confirm the file is named userChrome.css and is in the active profile's chrome folder. Check that toolkit.legacyUserProfileCustomizations.stylesheets is set to true, then restart Firefox. Firefox interface customizations may need updates after browser changes.
